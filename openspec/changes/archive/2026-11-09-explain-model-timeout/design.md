# Design

## Context

Адаптер LLM преобразует таймаут и другие ошибки HTTP в `LlmError`. CLI выводит эту ошибку с кодом 1, а веб-обработчик возвращает форму с HTTP 503 и исходными полями.

## Goals / Non-Goals

**Goals:** Дать обоим интерфейсам возможность распознать таймаут и предложить повторить запрос.

**Non-Goals:** Автоматические повторы, настройка времени ожидания и смена модели.

## Decisions

- Обрабатывать `httpx.TimeoutException` перед общим `httpx.HTTPError` и преобразовывать её в подкласс `LlmError`. Так оба интерфейса смогут распознать таймаут без разбора строки исключения.
- Использовать существующие ветки обработки ошибок CLI и веб-формы. Они уже завершают попытку до записи результата.

## Risks / Trade-offs

Таймаут может возникнуть на этапе подключения или ожидания ответа. Проверить оба случая через mock HTTP и сохранить текущие коды завершения интерфейсов.
