# generation-timeout Specification

## Purpose
Помочь пользователю распознать таймаут генерации и повторить запрос из CLI или веб-формы.

## Requirements

### Requirement: Сообщение о таймауте модели

При таймауте вызова модели Misterio SHALL сообщить об истечении времени ожидания, предложить повторить запрос и завершить текущую попытку без сохранения результата.

#### Scenario: Таймаут в CLI

- **WHEN** вызов модели через `misterio run` завершается таймаутом
- **THEN** CLI выводит сообщение о таймауте в stderr, возвращает код 1 и не создаёт файлы результата

#### Scenario: Таймаут в веб-форме

- **WHEN** вызов модели при отправке веб-формы завершается таймаутом
- **THEN** форма возвращается с HTTP 503 и сообщением о таймауте, сохраняет текст задачи и выбранный навык для повторной отправки, а файлы результата не создаются
